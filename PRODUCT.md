# Product

Fantasy **deathmatch**, **capture the flag**, and **PvE mini-scenarios** in a Quake 3 Arena-style shooter: orcs, elves, dwarves, humans, and other creatures in the same arena.

This game is **free and open source**. It lives on GitHub. Anyone can play. Anyone can drop in a character (GLB), build a map, or fix a bug.

It targets **10+ year-old PCs** (Godot Compatibility renderer, no heavy PBR requirement). If you want a match, you should be able to join.

The code stays free. Multiplayer is a small hosted server — a few dollars a month — so the lights stay on without selling the game.

---

## Ürün

Orklar, elfler, cüceler, insanlar ve diğer fantastik yaratıklar; **Quake 3 Arena** tarzı bir nişancıda **deathmatch**, **capture the flag** ve **PvE mini senaryolar**.

Oyun **ücretsiz ve açık kaynak**. GitHub’da duracak. İsteyen oynar. İsteyen karakter (GLB) ekler, map yapar, bug çözer.

**10 yıllık PC’lerde** de çalışması hedef: düşük donanım, Compatibility renderer. Kursun, girsin, oynasın.

Oyun satılmaz. Çok oyunculu için ayda birkaç dolarlık bir sunucu tutulur; monetizasyon bu kadar.

Solo veya grup: kısa map’ler, birinde omurgasızlara ateş, diğerinde zombiler — her senaryo kendi haritası ve yaratık seti.

## Modes

- **Deathmatch** — frag limit, everyone vs everyone (ships today).
- **Capture the Flag** — two flags, two bases (planned).
- **PvE** — solo or co-op mini scenarios, one map / one creature set each (planned). Example: invertebrates on one map, zombies on another. Drop-in GLB enemies welcome.

## Contribute

| You can… | How |
| --- | --- |
| Play | Clone the repo, open in Godot 4.7.2, F5 |
| Add a character | Drop a `.glb` (Idle / Walk / Run / Jump clips if you have them) under `assets/` |
| Add a map | CSG / mesh scene the arena can instance |
| Fix a bug | Pull request |

No asset store required. Procedural arena plates and weapon skins are already generated in code.

## Hardware

Godot **4.7.2**, **GL Compatibility**, windowed by default. No ray tracing, no high-end GI. Old integrated GPUs are in scope.

## Money

- **Client / source:** free, MIT, GitHub.
- **Multiplayer server:** cheap VPS, a few USD per month, run by the project so people can find a game.

This is not a live-service shop. No paid skins behind the engine. If you host your own dedicated box, you can.
